# Global Working Rules

- Read repository instructions and existing code before changing anything.
- Clarify requirements when a consequential choice cannot be inferred.
- Keep changes minimal, scoped, and consistent with project conventions.
- Preserve unrelated user changes; never discard or overwrite them.
- Add or update tests for changed behavior when practical.
- Run the most relevant available checks and report failures honestly.
- Do not weaken tests, validation, security controls, or error handling to pass checks.
- Never expose secrets or commit credentials, generated artifacts, or unrelated files.
- Avoid destructive commands and external side effects unless explicitly requested.
- Do not create, amend, or push commits unless explicitly requested.
- In reviews, report actionable findings first with file and line references.
- State assumptions, validation performed, and any remaining risks.
